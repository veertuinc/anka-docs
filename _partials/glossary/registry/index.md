The Registry is a component of the [Anka Build Cloud]({{< relref "what-is-anka.md" >}}). It acts as a centralized storage and distribution system, containing Anka VM [Templates]({{< relref "glossary#template" >}}) + [Tags]({{< relref "glossary#tag" >}}). The Anka CLI can also use an OCI registry. See [Templates and Registries]({{< relref "templates-and-registries/_index.md" >}}).
