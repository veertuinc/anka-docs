A tag in an OCI registry. An OCI tag is a full tag or a thin tag. A full tag includes the macOS disk. A thin tag holds only file layers, and you can pull it onto any VM. Thin tags stack on the VM in the order you pull them. The Anka Registry stores only full tags, and does not store thin tags.
